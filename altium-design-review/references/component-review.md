# Component decisions

The shared component qualification criteria are maintained in
[hw-skills / hardware-design-review](https://github.com/hornej/hw-skills/blob/main/hardware-design-review/references/component-review.md).
Read that reference from the installed `hardware-design-review` skill when
available, or use the linked canonical copy.

For Altium, first resolve the exact physical instance, channel and assembly
variant using [schematic and variant evidence](schematic-variants.md). Apply the
shared electrical and package checks to those verified circuit connections.

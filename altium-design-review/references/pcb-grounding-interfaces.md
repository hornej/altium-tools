# Grounding and attached-board interfaces

The shared engineering checks are maintained in
[hw-skills / hardware-design-review](https://github.com/hornej/hw-skills/blob/main/hardware-design-review/references/pcb-grounding-interfaces.md).
Read that reference from the installed `hardware-design-review` skill when
available, or use the linked canonical copy.

In Altium, inspect actual saved/live copper and compiled pin membership on both
boards. Use the project's native stackup, assembly variants and
[PCB rule/xSignal evidence](pcb-rules-xsignals.md) for layer transitions and
end-to-end constraints. Record whether the observed editor state was saved.
